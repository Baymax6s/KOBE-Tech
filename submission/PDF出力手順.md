# 提出物の PDF 変換手順

提出用の `README.md` を PDF に書き出し、Google ドライブへ提出するための手順です。
日本語と画像を含むため、**日本語フォントが自動で埋め込まれる VS Code 拡張「Markdown PDF」** を主な方法として推奨します。

## このディレクトリの構成

```text
submission/
├── README.md          ← 提出用の本文（これを PDF に変換する）
├── PDF出力手順.md      ← このファイル
└── assets/            ← README.md から参照する画像
    ├── 01-article-list.png
    ├── 02-article-detail.png
    └── ...
```

画像は `README.md` から `assets/xxx.png` という相対パスで参照しています。
**PDF に変換するときは `README.md` と `assets/` を同じ階層に置いたまま**行ってください。別の場所へ `README.md` だけ移すと画像が表示されません。

---

## 方法A: VS Code 拡張「Markdown PDF」（推奨）

GUI だけで完結し、日本語フォントも自動で扱われるため、最も確実で簡単です。

### 1. 拡張機能をインストール

1. VS Code を開く
2. 左の拡張機能アイコン（四角が4つのマーク）をクリック
3. 検索欄に `Markdown PDF` と入力
4. 作者が **yzane** の「Markdown PDF」をインストール

### 2. PDF に書き出す

1. `submission/README.md` を VS Code で開く
2. エディタ上で**右クリック**
3. メニューから **「Markdown PDF: Export (pdf)」** を選ぶ
4. 変換が走り、同じ `submission/` フォルダに **`README.pdf`** が生成される

> 初回は内部でブラウザエンジン（Chromium）のダウンロードが走り、少し時間がかかることがあります。完了するまで待ってください。

### 3. 確認

- `README.pdf` を開き、**画像がすべて表示されているか**・**日本語が文字化けしていないか**を確認します。
- 問題なければ、この `README.pdf` を Google ドライブへアップロードして提出します。

---

## 方法B: ブラウザの印刷機能（拡張を入れたくない場合）

VS Code 拡張を入れられない環境向けの代替手段です。レイアウト調整は手作業になります。

1. `README.md` を Markdown プレビューできるツール（VS Code のプレビュー、GitHub 上の表示など）で開く
2. ブラウザの**印刷**（`Cmd + P`）を開く
3. 送信先（プリンタ）を **「PDF に保存」** に変更
4. 必要に応じて余白・倍率を調整し、保存

> GitHub 上のプレビューから印刷する場合、リポジトリを push 済みであれば画像も一緒に表示されます。ローカルのプレビューでは画像が出ないツールもあるため、その場合は方法A を使ってください。

---

## 提出までの流れ（まとめ）

1. `submission/README.md` を最新の内容に更新する
2. 方法A（推奨）で `README.pdf` を書き出す
3. PDF を開いて画像・日本語の表示を確認する
4. Google ドライブの提出先に `README.pdf` をアップロードする
