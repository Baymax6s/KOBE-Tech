# 柱3: 学内に最適化された分類＝自由タグ

## ひとこと（説明スライドで言うこと）

「タグで記事を分類・絞り込みできる。ポイントは**タグの語彙が神戸電子に最適化**されていること。Qiita / Zen の汎用タグ（React, AWS…）ではなく、**`C言語課題36` `C#課題24` `Java課題11`** のような**学内カリキュラムの語彙**でつながれる。だから『今やってるあの課題』にまっすぐ辿り着ける。」

## 操作（20〜40秒・録画推奨）

1. `/articles` を開く。タグのドロップダウン（絞り込み）を開き、**学内タグが並ぶ様子**を見せる
2. **`C言語課題36`** を選択 → URL が **`/articles?tag=C言語課題36`** になり、該当記事だけに絞られる
3. もう一つ **`C#課題24`** に切り替えて、別の課題に瞬時に移れることを見せる
4. 比較で汎用タグ（`Go` `Vue` など）も並んでいることに触れ、「**汎用と学内特化が同居**できる」と添える

## 見せどころ

- 学内語彙が画面に出た瞬間に「これは**学校専用**なんだ」と一目で伝わる。ここが「Qiitaでよくない?」を打ち消す決定打
- タグは記事に紐づく。絞り込み→記事→その中のQ&A、という導線が柱2・柱4につながる
