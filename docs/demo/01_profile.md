# 柱1: 活動の透明化＝プロフィール

## ひとこと（説明スライドで言うこと）

「プロフィールが**その人の活動の通信簿**になる。投稿・いいね・ベストアンサー獲得が一覧で見える＝**活動が透明化**される。これが『仲間の活動が見える→モチベが続く』の入口です。」

## 操作（20〜40秒・録画推奨）

1. `渡辺翔太` でログイン（または未ログインのまま記事から著者名をクリックでも可）
2. ヘッダーから **プロフィール**（自分）へ、または URL で **`/profile/7`**（渡辺翔太）を開く
3. プロフィール画面で次を順に指し示す:
   - アバター画像・自己紹介
   - **タブ**を切り替えて「投稿した記事」「いいねした記事」
   - **ベストアンサー獲得**（学内課題で複数獲得している＝頼れる先輩）
4. 比較として `小林優子`（`/profile/10` 付近・プロフィール最小）を一瞬見せると「活動が無い人は本当に何も無い＝透明」だと伝わる（任意）

## 見せどころ

- 「**何をどれだけやってきたか**が一目で分かる」ことを強調する
- ここで渡辺翔太の充実したプロフィールを見せておくと、通しデモ（05）の「ベストが増える瞬間」が効いてくる伏線になる
