# 柱4: 書きやすさ＝Markdown（記事作成をライブで）

## ひとこと（説明スライドで言うこと）

「記事は **Markdown** で書ける。見出し・太字・リスト・**コードブロック**（ハイライト付き）。Markdown は **GitHub の世界標準の記法**（GitHub は全世界 **約1.8億ユーザー**）。**キーボードのショートカット**でも、**ツールバーのボタン**でも書けるので、記法を知らなくても始められて、知っていれば速い。」

> 「回答にもコードが綺麗に乗る」のは柱2のデモで見せているので、ここは**記事作成画面そのもの**にフォーカスする。

## このデモのゴール

記事作成画面で **(1) ショートカットで書く → (2) ツールバーで書く → (3) プレビュー → (4) 用意した本文を貼ってコードブロックを確認 → 投稿 → 記事詳細できれいに表示** までをライブで見せる。

## 準備

- **投稿者アカウント**（例: **高橋美咲** / `Password`）でログイン
- 画面の**右下にキー入力オーバーレイ**を表示するアプリを重ねておく（キー操作が視聴者に見える）
  - macOS: **KeyCastr**（無料）
  - Windows: **Carnac** など
- `/articles/new`（ヘッダーの「投稿」）を開く

## 操作（ライブ）

1. **タイトル**を入力（例:「fetch でAPIを叩く最小サンプル」）
2. **ショートカットで書く**（オーバーレイにキーが映る）
   - 行頭で `#` → スペース で**見出し**になる、と実演（記法そのものを見せる）
   - 文字を選択して **⌘B（Ctrl+B）** で**太字**、**⌘I** で斜体
3. **ツールバーで書く** — 本文エディタ上部のボタンを使い、選択範囲を装飾できることを見せる
   - 並び: **太字 / 下線 / 斜体 / 取り消し線**、見出し、引用、リスト、**インラインコード / コードブロック**、表 …
   - 「記法を覚えていなくても、**ボタンで Markdown が書ける**」と言う
4. **プレビュー** — 本文エリア上の **「プレビュー」タブ**に切り替え、装飾が描画される様子を見せる（空のときは記法チートシートが出る）
5. **本文を貼り付け** — 「編集」タブに戻り、下の貼り付け用データで**本文を差し替え**（全選択 → 貼り付け）
6. もう一度**プレビュー** — **コードブロックがハイライト表示**されることを確認
7. **投稿** — 投稿後、**記事詳細**でも見出し・リスト・コードブロックがきれいに表示されることを見せて締める

## 貼り付け用データ（クリップボード履歴に入れておく）

### タイトル

```text
fetch でAPIを叩く最小サンプル
```

### 本文（コードブロック付き・枠の中身をそのままコピー）

~~~~text
# fetch でAPIを叩く最小サンプル

フロントから API を呼ぶ、いちばん小さい例です。**まずは1本動かす**のが理解の近道。

## 取得して表示するだけ

```ts
const res = await fetch('/api/articles')
const articles = await res.json()
console.log(articles)
```

- `await` で結果を待つ
- `res.json()` で JSON に変換

慣れてきたら、型を付けて安全にしていきましょう。
~~~~

## 見せどころ

- 「GitHub標準＝1.8億ユーザーの記法」という**規模感の数字**を一度だけ口に出す
- **ショートカット → ツールバー → 記法**の3通りで書けることで、「初心者にも経験者にもやさしい」を伝える
- コードが**ベタ打ちでなくハイライトされて**いることを画面で見せる
