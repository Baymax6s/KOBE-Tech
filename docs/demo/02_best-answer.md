# 柱2: 貢献の可視化＝質問 → 回答 → ベストアンサー（ライブ・2アカウント）

## ひとこと（説明スライドで言うこと）

「分からないことを質問でき、仲間が回答する。さらに**ベストアンサー**で『どの回答が一番役に立ったか』を可視化する。良い回答をした人の**貢献がプロフィールに積み上がる**＝『モチベが続く』の駆動装置です。Stack Overflow と違い、答えるのは**顔の見える学内の仲間**。」

## このデモのゴール

**質問の投稿 → 回答（コード付き）→ ベストアンサー選択 → 回答者のプロフィールで獲得数が +1** までを、2人のユーザーを同時に操作してライブで見せる。

## 準備（2アカウント同時ログイン）

- ブラウザの**通常ウィンドウ**と**プライベート（シークレット）ウィンドウ**を1つずつ開く
  - ウィンドウA … **中村大輔**（質問者）でログイン
  - ウィンドウB … **渡辺翔太**（回答者）でログイン
- パスワードは2人とも `Password`
- 舞台の記事:「**C言語課題36：ポインタのイメージを掴む**」（`/articles?tag=C言語課題36` から開く）
- 開始前に、ウィンドウBで **渡辺翔太のプロフィール `/profile/7`** を開き、**現在のベストアンサー獲得数（2件）**を一度映しておく（あとで +1 を見せる伏線）

## 操作（ライブ）

1. **【A: 中村】質問を投稿** — 記事のリプライ欄で種別「質問」を選び、下の質問文を貼り付けて投稿
2. **【B: 渡辺】回答を投稿** — Bのウィンドウで同じ記事を開き（再読み込み）、その質問に「回答する」→ 下の回答文（コードブロック付き）を貼り付けて投稿
3. **【A: 中村】ベストアンサーに選ぶ** — Aのウィンドウを再読み込み → 渡辺の回答の「**ベストアンサーに選ぶ**」を押す → 👑 が付く
4. **【B: 渡辺】プロフィールで確認** — Bの `/profile/7` を再読み込み → **ベストアンサー獲得が 3件に増えている**／獲得記事一覧にこの記事が並ぶ

## 貼り付け用データ（クリップボード履歴に入れておく）

### ① 質問（中村が投稿）

```text
ポインタを関数の引数に渡して、関数の中から呼び出し元の変数を書き換えたいのですが、値が変わりません。なぜでしょう？
```

### ② 回答（渡辺が投稿・コードブロック付き）

下の枠の**中身をそのままコピー**（` ```c ` も含めて貼り付ける）:

~~~~text
値渡しだと「コピー」を書き換えているだけなので、呼び出し元には反映されません。**ポインタを渡して、その先を書き換える**必要があります。

```c
void increment(int *n) {
    (*n)++;            // 住所をたどって本体を書き換える
}

int main(void) {
    int x = 10;
    increment(&x);     // x の「住所」を渡す
    printf("%d\n", x); // 11
}
```

ポイントは「`&x` で住所を渡す」「`*n` で住所の先を触る」の2点です。
~~~~
