# 柱2: 貢献の可視化＝質問 → 回答 → ベストアンサー

## ひとこと（説明スライドで言うこと）

「分からないことを質問でき、仲間が回答する。さらに**ベストアンサー**で『どの回答が一番役に立ったか』を可視化する。良い回答をした人の**貢献が記録に残る**＝『モチベが続く』の駆動装置です。Stack Overflow と違い、答えるのは**顔の見える学内の仲間**。」

## 操作（20〜40秒・録画推奨）

1. `/articles?tag=C言語課題36` を開く →「C言語課題36：ポインタのイメージを掴む」記事へ
2. 記事下部の**リプライ欄**へスクロール。フィルタ「質問」を見せると質問だけ絞れる
3. 次を順に指す:
   - 中村大輔（初心者）の**質問**
   - 渡辺翔太の**回答**に付いた **👑 ベストアンサー** バッジ
4. 続けて、ベストアンサーが付いた人の**プロフィール**に実績が積まれることへ言及（柱1と接続）
