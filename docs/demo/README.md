# デモ操作手順（発表用）

15分発表の「製品セクション」で使う、画面操作の台本です。
動画録画でも、前での実演でも、この手順どおりに操作すれば再現できます。

## 発表の中核命題（毎回ここに紐づけて語る）

> **プロフィール＝活動の透明化 → 仲間の活動が見える → モチベが続く → 学習が続く → 技術力が上がる**

Qiita / Stack Overflow との違いは「**顔の見える学内の仲間**」であること。各機能はこの物語のどこに効くかをひとことで添える。

## 製品セクションの構成（4本柱 + 通しデモ）

| # | ファイル | 柱 | 尺の目安 |
| --- | --- | --- | --- |
| 1 | [01_profile.md](01_profile.md) | 活動の透明化＝プロフィール | 20〜40秒 |
| 2 | [02_best-answer.md](02_best-answer.md) | 貢献の可視化＝質問→回答→ベストアンサー | 20〜40秒 |
| 3 | [03_tags.md](03_tags.md) | 学内に最適化された分類＝自由タグ | 20〜40秒 |
| 4 | [04_markdown.md](04_markdown.md) | 書きやすさ＝Markdown | 20〜40秒 |
| 5 | [05_walkthrough.md](05_walkthrough.md) | 通しデモ（命題が1本につながる山場） | 1.5〜2分 |

進め方: 各柱は「説明スライド → デモ映像（無音ループ）」を同時に流す。4本柱のあと、最後に通しデモを1本流す。

**デモの基本姿勢**: 既存データを眺めるだけでなく、**実際に投稿・追加するライブ操作**で「使える感」を見せる。特に柱2（質問→回答→ベスト）は**2アカウント同時操作**で行う。投稿に使う文章は各ファイルの「貼り付け用データ」にまとめてあるので、**事前にクリップボード履歴へ入れて**おくと録画がスムーズ。

## 事前準備

### 1. データ投入（毎回リセットしてから録る）

```bash
cd api
docker compose down -v      # 既存データを全消去
docker compose up -d         # postgres / migrate / minio が起動し seed が入る
cd ../app && npm run dev      # フロント起動
```

> 柱2・通しデモで質問やベストアンサーを投稿・選択すると状態が変わる。**録り直すときは必ず `down -v` でリセット**してから。
> 回答・記事の **Markdown / コードブロック描画**は develop に統合済み（旧 `feature/302`）。最新の develop 系で録画すれば追加対応は不要。

### 2. 2アカウント同時ログイン（柱2・通しデモ用）

質問する人と回答する人を**同時に操作**するため、2つのセッションを用意する。

- ブラウザの**通常ウィンドウ**と**プライベート（シークレット）ウィンドウ**を1つずつ開き、別アカウントでログインする
- 例: 通常=**中村大輔**（質問者）、プライベート=**渡辺翔太**（回答者）

### 3. キーボード入力オーバーレイ（柱4用）

記事作成のショートカット操作を見せるため、**キー入力を画面右下に表示するアプリ**を重ねる。

- macOS: **KeyCastr**（無料）／ Windows: **Carnac** など

### 4. ログインアカウント

ログインは **ユーザー名 + パスワード**。**全員パスワードは `Password`**。

| ユーザー名 | デモでの役回り | プロフィール |
| --- | --- | --- |
| `中村大輔` | 初心者・質問する側（id 9） | 既定アイコン |
| `渡辺翔太` | 頼れる先輩・ベストアンサー多数（id 7） | アバターあり |
| `鈴木健一` | 講師（id 5） | アバターあり |
| `高橋美咲` | 学生・記事/ベストあり（id 6） | アバターあり |

## デモ用の主役データ

- **学内特化タグ**: `C言語課題36` / `C#課題24` / `Java課題11`（ほかに `プロジェクト管理` `デザイン思考`）
- **学内課題記事**: 「C言語課題36：ポインタのイメージを掴む」「C#課題24：例外処理でよくある詰まり」「Java課題11：継承とインターフェースの使い分け」
- **頼れる先輩** `渡辺翔太` は学内課題で**ベストアンサーを2件獲得済み**。通しデモでC#のベストを選ぶと**3件**に増える＝透明化の締めに使う。
