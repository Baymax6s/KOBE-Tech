# 03. パッケージデザイン

> 状態: たたき台 / 要チーム合意（キャッチコピーはチームで磨く）

製品を「箱」に見立て、ユーザーが棚で手に取りたくなるキャッチコピーと、嬉しさ（ベネフィット）を3つ書く。

## キャッチコピー（案）

> **「ひとりで詰まらない。仲間が、見える。」**

別案:
- 「神戸電子の、学びが見える場所」
- 「わからないを置いていける。やってることを残していける。」

## 3つの嬉しさ

1. **わからないが、置いていける**
   詰まったことを質問でき、記事やベストアンサーとして残る。次の人の助けにもなる。
2. **やったことが、自分のページに積み上がる**
   投稿・回答・制作物がプロフィールに集約され、「自分がどれだけやってきたか」が形になる。
3. **仲間の活動が、見える**
   投稿者からプロフィールへ辿れば、同じ学校の仲間が何をやっているかがわかる。それが続ける動機になる。

## 差別化の見せ方

「Qiita / Stack Overflow の学内版」ではなく、**顔の見える仲間の活動が見える**ことを前面に出す。
活動の透明化（嬉しさ 2・3）が、本プロダクトを箱として選ぶ理由。
