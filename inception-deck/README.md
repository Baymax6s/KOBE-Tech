# インセプションデッキ — プログラミング情報共有サイト（仮）

アジャイルサムライ（Jonathan Rasmusson）の10の課題に沿った、本プロダクトの共通認識ドキュメントです。
「なぜ作るのか」と「何を作らないのか」をチームで握るためのものです。

## このデッキの軸（最初に読む）

本プロダクトの中核の仕掛けは、エレベーターピッチの差別化要素から導いた次の因果です。

> **充実したプロフィール（＝活動の透明化） → 既存の投稿者導線で他人の活動が見える → モチベーションが続く → 学習が継続する → 結果として技術力が上がる**

「情報共有サイト」そのものが技術力を上げるのではなく、**学習が続くこと**が技術力向上の本質、という立場を取ります。
以降のすべての判断（やらないこと・トレードオフ・リスク）は、この軸に効くかどうかで決めています。
