# 08. 期間を見極める

> 状態: たたき台 / 要チーム合意（実際の学校スケジュールに合わせて埋める）

「数週間か、数ヶ月か、それ以上か」をざっくり掴む。正確な見積もりではなく桁感の共有。

## 前提

- 学校プロジェクトのため**期間は基本固定**（動かせる軸ではない）。実日程はここに記入する
- 既に Qiita 相当（記事・Q&A・タグ・いいね・プロフィール・認証）は実装済み。ゼロからではない

## ざっくりの桁感（案）

| フェーズ | 中身 | 目安 |
|----------|------|------|
| 基盤（済） | 記事 / Q&A / タグ / いいね / プロフィール / 認証 | 実装済み |
| 中核強化 | プロフィールの充実（制作物・投稿履歴の集約）・投稿者名導線の整備 | 本プロジェクトの主戦場 |
| 仕上げ | コールドスタート対策のシード投入・投稿UXの摩擦取り（[07](07_risks.md)） | 期間末 |

> 確定スケジュール（スプリント数・各スプリント期間・締切）はチームで記入する。
