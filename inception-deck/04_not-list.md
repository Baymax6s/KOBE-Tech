# 04. やらないことリスト

> 状態: 確定

有限の期間で中核（[01](01_why.md) の透明化×継続学習）に集中するため、**今回はやらない**ものを宣言する。
「中核に直接効かないもの」を外す、という基準で選んでいる。

## やる

- 記事投稿（Markdown）・タグ
- Q&A（質問 / 回答 / ベストアンサー）
- いいね
- プロフィール（bio・制作物・投稿履歴の集約）← **差別化の中核。ここを厚くする**
- 投稿者名からプロフィールへの導線（既存動線に乗せる）

## やらない（今回は）

| やらないこと | 理由 |
|--------------|------|
| リアルタイム通知 / DM / チャット | WebSocket・通知基盤は実装が重い。透明化は「見に行けば見える」で成立し、中核に不要 |
| ランキング / ポイント / バッジ | 透明化はプロフィールの充実で表現する方針。競争型ゲーミフィケーションは初学者の心理的ハードル([07](07_risks.md))を上げる懸念もありスコープ外 |
| 学校アカウント SSO 連携 | 「閉じた学内コミュニティ」は理念として掲げるが、SSO の実装は今回やらない（[05](05_neighbors.md)・[07](07_risks.md) のギャップ参照） |
| モバイルアプリ / 外部SNS（X・GitHub等）連携 | プラットフォームは Web（レスポンシブ）に絞る |

## あとで考える（保留）

- 全文検索の高度化
- 通報・モデレーション（過疎を脱して人が増えてから現実的な課題になる）
- 活動フィード / 貢献グラフ（透明化の"能動的に見せる"強化版。今回はプロフィール集約で代替）
